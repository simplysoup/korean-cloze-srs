# Phase 8 — Admin & Analytics

> **Status:** 💭 Future

## Goals

Provide tools for managing cards and understanding review patterns.

## Tasks

### 8.1 Card Browser
- Browse all grammar points and their cloze cards
- Search/filter by category, level, tags
- View card details including answer, hints, and review statistics

### 8.2 Card Editor
- CRUD UI for creating/editing grammar points and cloze cards
- Live preview of cloze card rendering
- Validation for Korean sentence structure

### 8.3 Review Analytics Dashboard
- Charts showing review history, accuracy rates, and FSRS state distribution
- Per-grammar-point difficulty analysis
- Session summary (cards reviewed, time spent, accuracy)
- Retention curve visualization

### 8.4 User Management
- Admin view of registered users
- Review statistics per user
- Account management (reset password, disable accounts)

## Dependencies
- Charting library (e.g. Chart.js, D3, or Svelte-specific)
- Admin role/permission system
